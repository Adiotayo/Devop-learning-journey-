# Day 1: Linux Basics

## Commands I practised

### pwd
Shows the current folder I am inside.

### ls
Lists the files and folders in my current location.

### ls -la
Lists all files and folders, including hidden ones, with extra details.

### cd
Moves me into another folder.

### touch
Creates a new empty file.

### find
Searches for files or folders.

## What I learned today

Today I learned how to open the VS Code terminal, check my current folder, list files, move into folders, create a file, and search for files from the command line.
