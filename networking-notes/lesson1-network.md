# Lesson 1 - What is a Network

## Definition

A network is a group of devices connected together so they can communicate.

## Examples

- Laptop
- Phone
- Server
- Router

## Internet

The internet is a network of networks.

## Server

A server provides services.

## Client

A client requests services.

## Client Server Model

Client sends request.
Server sends response.

# Lesson 3 - HTTP, HTTPS and curl

## HTTP

HTTP is used for communication between browsers and web servers.

Default Port: 80

## HTTPS

HTTPS is the secure version of HTTP.

Default Port: 443

HTTPS encrypts communication.

## curl

curl allows us to make web requests from the terminal.

Examples:

curl https://example.com

curl -I https://google.com

curl -L https://barnardos.org.uk

## HTTP Status Codes

200 = Success

302 = Redirect

404 = Page Not Found

500 = Server Error
