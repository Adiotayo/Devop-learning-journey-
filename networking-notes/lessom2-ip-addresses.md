# Lesson 2 - IP Addresses

## What is an IP Address?

An IP address is a unique address assigned to a device on a network.

Example:

192.168.1.10

## Why IP Addresses Matter

Devices use IP addresses to communicate.

## IPv4

IPv4 consists of four numbers separated by dots.

Example:

192.168.1.10

## Private IP Address

Used inside a local network.

Examples:

192.168.x.x
10.x.x.x

My Private IP:

192.168.1.134

## Public IP Address

Used on the internet.

A router normally has a public IP address.

## DNS

DNS stands for Domain Name System.

DNS translates domain names into IP addresses.

Example:

google.com

↓

142.250.xxx.xxx

DNS is often called the phonebook of the internet.
